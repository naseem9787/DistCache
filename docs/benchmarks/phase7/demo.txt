# 3 nodes behind the router. Load 3000 keys through the router:
$ redis-cli -p 7700 DBSIZE
3000

# where do keys live? (each node's own DBSIZE, bypassing the router)
node 1: 1023
node 2: 990
node 3: 987

$ redis-cli -p 7700 RING LOOKUP key:42
a
$ redis-cli -p 7700 GET key:42
value-42

# hash tags keep related keys together:
$ redis-cli -p 7700 RING LOOKUP {user:7}:profile
a
$ redis-cli -p 7700 RING LOOKUP {user:7}:cart
a

# add a 4th node WITHOUT migration: about a quarter of the keys now miss
$ redis-cli -p 7700 RING ADD d 127.0.0.1 7704
OK
keys that now miss: 690 of 3000

# remove it again, then add it WITH migration: every key stays reachable
$ redis-cli -p 7700 RING REMOVE d
OK
$ redis-cli -p 7700 RING ADD d 127.0.0.1 7704 MIGRATE
OK scanned=3000 moved=690 superseded=0 vanished=0 errors=0
keys that miss: 0 of 3000

node 2: 789
